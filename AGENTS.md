# Regras para agentes

## Leitura obrigatória antes de alterar arquivos

Antes de qualquer alteração neste repositório, inclusive código, estilos, assets, testes ou configuração:

1. Leia as orientações do vault em `../iweti-obsidian/AGENTS.md`.
2. Leia o índice geral em `../iweti-obsidian/iweti.md`.
3. Leia a documentação deste projeto em `../iweti-obsidian/iweti-portifolio/iweti-portifolio.md` e as notas existentes relacionadas à tarefa.
4. Confira o estado e o diff locais para preservar alterações existentes.

O vault fica em `/home/nicolas/dev/iweti-obsidian`. Se ele estiver indisponível, informe o impedimento e não altere arquivos até conseguir consultar a documentação necessária. Quando faltar uma nota específica, use o índice disponível e confira o comportamento no código; não invente requisitos nem crie documentação para suprir a ausência por iniciativa própria.

## Documentação centralizada

- Não crie documentação na raiz deste repositório nem em pastas locais como `docs/`. Isso inclui planos, relatórios de implementação ou testes, roteiros de design e registros de prompts.
- Não crie nem atualize documentação automaticamente ao implementar uma tarefa. Só produza documentação quando o usuário solicitar explicitamente.
- Quando houver solicitação de documentação, utilize o projeto correspondente no vault `iweti-obsidian`, seguindo suas orientações e organização existentes.
- Não duplique documentação do vault neste repositório. Não atualize o README como efeito colateral de alterações de código.
- Registre preferências duráveis na memória, conforme solicitado pelo usuário, sem gerar documentos adicionais no repositório.
- Este `AGENTS.md` é o arquivo de instruções solicitado pelo usuário e constitui a exceção às restrições de documentação na raiz.
